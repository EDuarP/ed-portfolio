## 📖 About

A clean, fast and dependency-free single-page portfolio that presents Eduardo Duarte's
profile, featured projects, technical skills and CV. Built with plain HTML, CSS and
vanilla JavaScript — no frameworks, no build step — and deployed on GitHub Pages.

The site targets an audience in both English and Spanish and focuses on:

- **Machine Learning & AI Engineering** — end-to-end ML/AI systems, from data to production
- **Cloud** — Microsoft Azure & AWS
- **Data Science & Analytics**
- **IoT & hardware/software integration**
- **Software engineering**

## ✨ Features

- 🌐 **Bilingual UI (EN / ES)** — instant language switch driven by a lightweight `data-i18n` dictionary, no page reload
- 🖼️ **Image lightbox** — click any project image to open a full-screen gallery with previous/next and keyboard navigation (`← → Esc`)
- 📱 **Responsive layout** — adapts from mobile to desktop
- ⚡ **Zero dependencies / zero build** — pure static site, loads instantly
- 🧩 **Skills grid** with recognizable tech icons
- 📄 **One-click CV download**

## 🗂️ Featured projects

| Project | Description | Stack |
|---|---|---|
| **Sickle Cell Medical Chatbot** | Medical RAG system for Sickle Cell Anemia with automated PMC scraping and semantic search for evidence-based answers. | Python · FastAPI · RAG · LangChain |

| **Pig Weighing Management System** | Industrial data capture and reporting for pork processing, with serial communication, automated reports and operational dashboards. | Python · Pandas · Power BI |
| **Public Transportation Data Science** | ML and analytics to model and analyze public transport routes in Bucaramanga. | Python · Power BI · Machine Learning |

## 🛠️ Tech stack

- **Markup / styling:** HTML5, CSS3 (custom properties, flex / grid layout)
- **Behavior:** Vanilla JavaScript (i18n switch + lightbox)
- **Fonts:** Inter (Google Fonts)
- **Icons:** Simple Icons / Shields.io
- **Hosting:** GitHub Pages
